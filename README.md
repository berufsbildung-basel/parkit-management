## Project Management

This repository contains project management and ongoing working materials for the P.A.R.K.I.T project.

**It includes:**
- Project risks and open questions
- Stakeholders and project contacts
- Mind maps and project context
- Current tasks and priorities
- Ongoing research, ideas, and decisions
- Other intermediate project materials

This repository serves as a shared workspace for project-related information and ongoing work. 

**Finalized technical documentation is maintained in the main project repository: [parkit-service](https://github.com/berufsbildung-basel/parkit-service).**
