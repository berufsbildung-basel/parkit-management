## Project Management

This repository contains the project's ongoing project-management and working materials.

It is used for project context, current work, research, intermediate results, decisions and other supporting materials.

Finalized technical documentation is maintained in the main project [parkit-service](https://github.com/berufsbildung-basel/parkit-service) repository.

---

### Repository Structure

```
management/
├── README.md
├── CURRENT_TASKS.md
│
├── project-notes/
│   ├── meetings-notes.md
│   ├── problem.md
│   ├── risks.md
│   └── open-questions.md
│
├── project-context/
│   ├── mind-map/
│   └── glossary/
│
└── workstreams/
    ├── led-integration/
    ├── administration-approval/
    └── reservation-reminder/
```



**`project-context/`** - general project information needed to understand the project.

**`mind-map/`** — project structure, relationships and dependencies.

**`glossary/`** — project-specific terms and terminology.

**`CURRENT_TASKS.md`** -  high-level overview of the work currently in progress.

**`workstreams/`** - working materials organized by major project area.

**`project-notes`** - needed documentation of current work, milestones and blocks

---

### Each workstream contains:

- a README.md describing the goal, scope and expected outcome;
- research and other intermediate materials related to the work.

---

### Task Tracking
Tasks, subtasks, assignments and progress are managed separately in the project's task tracker.

This repository contains the working materials produced while carrying out that work.
